# Student Submission Checklist

- [ ] Check thesis title.
- [ ] Check student name and ID.
- [ ] Check supervisor name.
- [ ] Check department and faculty name.
- [ ] Check page numbering.
- [ ] Check table of contents.
- [ ] Check list of figures.
- [ ] Check list of tables.
- [ ] Check all figure captions.
- [ ] Check all table captions.
- [ ] Check all references are cited.
- [ ] Check spelling in Lao and English.
- [ ] Compile final PDF successfully.
- [ ] Submit only the final PDF unless the department requests source files.
